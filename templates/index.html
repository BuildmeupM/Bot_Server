  • 🤖 ระบบอัตโนมัติ: ระบบประมวลผลและบันทึกเอกสาร PDF อัตโนมัติ
  • 📧 ส่งอีเมลล์: ระบบส่งอีเมลล์อัตโนมัติ
  • 📋 คัดแยกเอกสาร: ระบบคัดแยกและจัดหมวดหมู่เอกสารอัตโนมัติ (กำลังพัฒนา)
  • 🔍 ตรวจภาษี: ระบบตรวจสอบความถูกต้องของข้อมูลภาษี
  • 📋 ยื่น ภ.ง.ด.1ก/กท.20ก: ระบบยื่นแบบแสดงรายการภาษีเงินได้หัก ณ ที่จ่าย (ภ.ง.ด.1ก) และแบบรายงานการจ่ายเงินได้ (กท.20ก)

🤖 ระบบอัตโนมัติ

ระบบประมวลผลและบันทึกเอกสาร PDF อัตโนมัติ

  • สแกนและประมวลผลเอกสารอัตโนมัติ - ระบบจะสแกนและประมวลผลไฟล์ PDF โดยอัตโนมัติ
  • จัดกลุ่มตามประเภทภาษี (VAT/NoneVat) - แยกเอกสารตามประเภทภาษีมูลค่าเพิ่ม
  • บันทึกลงระบบ PeakEngine - บันทึกข้อมูลลงระบบ PeakEngine อัตโนมัติ
  • ติดตามสถานะการประมวลผลแบบเรียลไทม์ - ดูสถานะการทำงานแบบเรียลไทม์
📂 ไปยังหน้าระบบอัตโนมัติ

📧 ส่งอีเมลล์

ระบบส่งอีเมลล์อัตโนมัติ

  • ส่งอีเมลล์เดี่ยวหรือหลายฉบับ - ส่งอีเมลล์ได้ทั้งแบบเดี่ยวและแบบหลายฉบับพร้อมกัน
  • รองรับไฟล์แนบ - สามารถแนบไฟล์ไปกับอีเมลล์ได้
  • ส่งแบบ HTML หรือ Text - รองรับการส่งทั้งแบบ HTML และข้อความธรรมดา
  • ประวัติการส่งอีเมลล์ - ดูประวัติการส่งอีเมลล์ทั้งหมด
📧 ไปยังหน้าส่งอีเมลล์

📋 คัดแยกเอกสาร

ระบบคัดแยกและจัดหมวดหมู่เอกสารอัตโนมัติ

  • คัดแยกเอกสารตามประเภท - จัดหมวดหมู่เอกสารอัตโนมัติ (กำลังพัฒนา)
  • จัดระเบียบเอกสาร - ย้ายเอกสารไปยังโฟลเดอร์ที่เหมาะสม (กำลังพัฒนา)
  • วิเคราะห์และจำแนกเอกสาร - ใช้ AI ในการจำแนกประเภทเอกสาร (กำลังพัฒนา)
  • จัดการและติดตาม - ติดตามเอกสารที่ผ่านการคัดแยกแล้ว (กำลังพัฒนา)
📋 ไปยังหน้าคัดแยกเอกสาร

🔍 ตรวจภาษี

ระบบตรวจสอบความถูกต้องของข้อมูลภาษี

  • ตรวจภาษีหัก ณ ที่จ่าย - ระบบตรวจสอบภาษีหัก ณ ที่จ่าย (กำลังพัฒนา)
  • ตรวจภาษีมูลค่าเพิ่ม - ตรวจสอบความถูกต้องของข้อมูลภาษีมูลค่าเพิ่ม
  • เปรียบเทียบข้อมูล - เทียบข้อมูลระหว่างงบทดลอง ไฟล์ OCR และภาษีซื้อ
  • รายงานผลการตรวจสอบ - แสดงผลการตรวจสอบแบบ step-by-step
🔍 ไปยังหน้าตรวจภาษี

📋 ยื่น ภ.ง.ด.1ก/กท.20ก

ระบบยื่นแบบแสดงรายการภาษีเงินได้หัก ณ ที่จ่าย (ภ.ง.ด.1ก) และแบบรายงานการจ่ายเงินได้ (กท.20ก)

  • ยื่นแบบ ภ.ง.ด.1ก - ระบบยื่นแบบแสดงรายการภาษีเงินได้หัก ณ ที่จ่าย
  • ยื่นแบบ กท.20ก - ระบบยื่นแบบรายงานการจ่ายเงินได้
  • อัพโหลดเอกสาร - อัพโหลดเอกสารที่เกี่ยวข้องได้ง่าย
  • ติดตามสถานะ - ติดตามสถานะการยื่นแบบรายเดือน
📋 ไปยังหน้ายื่น ภ.ง.ด.1ก/กท.20ก

📖 วิธีใช้งาน

  1. เลือกหน้าที่ต้องการ จากเมนูด้านบน
  2. ระบบอัตโนมัติ:
    • วาง path โฟลเดอร์ที่ต้องการประมวลผล
    • กด "เพิ่มงาน" เพื่อเริ่มประมวลผล
    • ติดตามสถานะได้จากหน้าจอ
  3. ส่งอีเมลล์:
    • ตั้งค่า SMTP ในแถบด้านข้าง
    • กรอกข้อมูลอีเมลล์และส่งได้ทันที
  4. คัดแยกเอกสาร:
    • ระบบกำลังอยู่ในขั้นตอนการพัฒนา
    • ฟีเจอร์ต่างๆ จะพร้อมใช้งานในอนาคต
  5. ตรวจภาษี:
    • เลือกเดือนภาษีและชื่อบริษัทที่ต้องการตรวจสอบ
    • ระบบจะตรวจสอบไฟล์งบทดลอง ไฟล์ OCR และไฟล์ภาษีซื้อ
    • เปรียบเทียบข้อมูลและแสดงผลการตรวจสอบแบบ step-by-step
  6. ยื่น ภ.ง.ด.1ก/กท.20ก:
    • เลือกบริษัทที่ต้องการยื่นแบบ
    • อัพโหลดเอกสารที่เกี่ยวข้อง (แบบ ภ.ง.ด.1, ใบแนบ ภ.ง.ด.1, แบบประกันสังคม, ใบแนบประกันสังคม)
    • ตรวจสอบสถานะข้อมูลรายเดือน
    • ส่งยื่นเอกสารได้ทันที

🔧 หมายเหตุ

  • ระบบนี้ต้องเชื่อมต่อกับ network drive (V:) เพื่อเข้าถึงข้อมูล
  • สำหรับการส่งอีเมลล์ ต้องตั้งค่า SMTP ก่อนใช้งาน
  • ใช้เมนูด้านบนเพื่อสลับระหว่างหน้าต่างๆ

🚀 คู่มือการติดตั้ง BotV3

ระบบประมวลผล PDF อัตโนมัติ

📦

การติดตั้งแบบอัตโนมัติ

วิธีที่ง่ายที่สุดสำหรับผู้ใช้ทั่วไป

1ดาวน์โหลดไฟล์

📁 ไฟล์ที่จำเป็น

• ไฟล์โปรแกรม BotV3 ทั้งหมด

• install_botv3.py

• setup.bat (Windows) หรือ setup.sh (Linux/Mac)

• requirements_setup.txt

2ตรวจสอบข้อกำหนดระบบ

💻 ข้อกำหนดระบบ

Python: เวอร์ชัน 3.8 หรือสูงกว่า

RAM: อย่างน้อย 4 GB

Storage: อย่างน้อย 1 GB พื้นที่ว่าง

OS: Windows 10+, macOS 10.14+, Ubuntu 18.04+

⚠️ ข้อควรระวัง

หากยังไม่มี Python กรุณาติดตั้งก่อน

ดาวน์โหลดได้ที่: https://www.python.org/downloads/

3รันการติดตั้ง

🖥️ Windows
# ดับเบิลคลิกที่ไฟล์ setup.bat # หรือรันใน Command Prompt: setup.bat
🐧 Linux / 🍎 macOS
# รันใน Terminal: ./setup.sh # หรือรัน Python โดยตรง: python3 install_botv3.py

💡 เคล็ดลับ

การติดตั้งจะใช้เวลาประมาณ 5-10 นาที ขึ้นอยู่กับความเร็วอินเทอร์เน็ต

ระบบจะติดตั้ง packages และ browsers อัตโนมัติ

4การตั้งค่าเริ่มต้น

⚙️ ไฟล์ที่สร้างขึ้น

• config_template.py - ไฟล์ template การตั้งค่า

• รหัส/Build000.json - ไฟล์ข้อมูลบริษัทตัวอย่าง

• รหัส/Build000.txt - ไฟล์ข้อมูล login ตัวอย่าง

• folder_settings/folder_settings.json - ไฟล์การตั้งค่าโฟลเดอร์

⚠️ ขั้นตอนสำคัญ

1. คัดลอก config_template.py เป็น config.py

2. แก้ไขข้อมูลใน config.py ให้ถูกต้อง

3. แก้ไขไฟล์ข้อมูลในโฟลเดอร์ 'รหัส/'

🔧 การตั้งค่าเพิ่มเติม

1การตั้งค่า LINE

📱 LINE Notify (แนะนำ)
# ใน config.py LINE_NOTIFY_TOKEN = "your_line_notify_token_here"

1. เข้า LINE Notify

2. สร้าง Token ใหม่

3. คัดลอก Token มาใส่ใน config.py

🤖 LINE OA (Messaging API)
# ใน config.py LINE_OA_CHANNEL_ACCESS_TOKEN = "your_channel_access_token" LINE_OA_DEFAULT_TO = "user_id_or_group_id"

1. สร้าง LINE Official Account

2. เปิดใช้งาน Messaging API

3. ใส่ Channel Access Token และ User ID

2การตั้งค่าโฟลเดอร์

📁 โครงสร้างโฟลเดอร์
# ใน config.py BASE_FOLDER = "V" # หรือ "Synology" MAIN_FOLDERS = ["A.โฟร์เดอร์หลัก", "AA.โฟรเดอร์หลัก"]

🚀 การเริ่มต้นใช้งาน

1เริ่มต้นระบบ

🖥️ Windows
# ดับเบิลคลิกที่ไฟล์ start_botv3.bat # หรือรันใน Command Prompt: python bot_gui_tkinter.py
🐧 Linux / 🍎 macOS
# รันใน Terminal: ./start_botv3.sh # หรือรัน Python โดยตรง: python3 bot_gui_tkinter.py

2โหมดการทำงาน

🖥️ Desktop GUI

ใช้งานผ่านหน้าต่าง GUI หลัก

เหมาะสำหรับการใช้งานทั่วไป

🌐 Web Control

ควบคุมผ่านเว็บเบราว์เซอร์

เหมาะสำหรับการใช้งานระยะไกล

python main_control.html # เปิดในเบราว์เซอร์

🔧 การแก้ไขปัญหา

❌ ปัญหาที่พบบ่อย

ไม่สามารถติดตั้ง Playwright ได้:

pip install --upgrade playwright playwright install chromium

ไม่พบไฟล์ config.py:

# คัดลอก template copy config_template.py config.py # Windows cp config_template.py config.py # Linux/Mac

ไม่สามารถเชื่อมต่อ LINE ได้:

• ตรวจสอบ LINE Token

• ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต

• ตรวจสอบ User ID หรือ Group ID

📞 การสนับสนุน

📖 คู่มือการใช้งาน

• หน้าหลัก

• แนะนำระบบ

• การใช้งาน

• การสร้างฐานข้อมูล

• การแก้ไขไฟล์

💡 เคล็ดลับการใช้งาน

• เริ่มต้นด้วยโหมด "กำหนดโฟลเดอร์เอง" เสมอ

• ตรวจสอบไฟล์ PDF ก่อนประมวลผล (ไม่มีรหัสผ่าน)

• ใช้ LINE Notify เพื่อรับผลลัพธ์ทันที

• ระบบจำกัดการประมวลผลสูงสุดที่ 60 รายการต่อครั้ง

# 🚀 BotV3 - ระบบควบคุมหลัก

## 📋 ภาพรวม

ระบบควบคุมหลักสำหรับ BotV3 ที่มี Web UI สวยงามและใช้งานง่าย

### ✨ คุณสมบัติ

- ✅ **UI สวยงาม**: ออกแบบด้วย Modern Design
- ✅ **2 โหมดการทำงาน**: อัตโนมัติ หรือ เลือกโฟลเดอร์เอง
- ✅ **ทดสอบระบบ**: ตรวจสอบความพร้อมก่อนรัน
- ✅ **แสดงสถานะ Real-time**: ดูสถานะการทำงานแบบเรียลไทม์
- ✅ **สถิติการทำงาน**: แสดงจำนวนโฟลเดอร์, ไฟล์, ความสำเร็จ

---

## 🎯 วิธีใช้งาน

### ขั้นตอนที่ 1: เริ่มระบบ API

```bash
cd "Z:\Build000 ทดสอบระบบ\ส่วนตัวเอ็ม\BotV3"
python control_api.py
```

คุณจะเห็น:
```
🚀 Starting BotV3 Control API...
📡 API available at: http://localhost:5000
🌐 Web UI available at: http://localhost:5000

💡 Press Ctrl+C to stop
```

### ขั้นตอนที่ 2: เปิด Web UI

เปิดเบราว์เซอร์ไปที่:
```
http://localhost:5000
```

### ขั้นตอนที่ 3: ใช้งาน UI

#### 🔍 สแกนโฟลเดอร์
1. กดปุ่ม **"🔍 สแกนโฟลเดอร์"**
2. ระบบจะแสดงจำนวนโฟลเดอร์และไฟล์ที่พบ

#### 🧪 ทดสอบระบบ
1. กดปุ่ม **"🧪 ทดสอบระบบ"**
2. ระบบจะตรวจสอบ:
   - โฟลเดอร์มีอยู่หรือไม่
   - โมดูลครบหรือไม่
   - Playwright พร้อมหรือไม่
   - LINE ตั้งค่าแล้วหรือไม่

#### ▶️ เริ่มทำงาน

**โหมดอัตโนมัติ (แนะนำ):**
1. เลือกโหมด **"โหมดอัตโนมัติ"**
2. กดปุ่ม **"▶️ เริ่มทำงาน"**
3. ระบบจะสแกนและประมวลผลทุกโฟลเดอร์อัตโนมัติ

**โหมดเลือกเอง:**
1. เลือกโหมด **"เลือกเอง"**
2. เลือกโฟลเดอร์ที่ต้องการ (checkbox)
3. กดปุ่ม **"▶️ เริ่มทำงาน"**

#### ⏹️ หยุดการทำงาน
1. กดปุ่ม **"⏹️ หยุด"** ระหว่างทำงาน
2. ระบบจะหยุดหลังจากประมวลผลโฟลเดอร์ปัจจุบันเสร็จ

## 📊 ส่วนต่างๆ ใน UI

### 1. การควบคุม (ซ้าย)
- **เลือกโหมด**: อัตโนมัติ / เลือกเอง
- **เลือกโฟลเดอร์**: สำหรับโหมดเลือกเอง

### 2. การทำงาน (ขวา)
- **▶️ เริ่มทำงาน**: เริ่มประมวลผลระบบ
- **🧪 ทดสอบระบบ**: ตรวจสอบความพร้อม
- **⏹️ หยุด**: หยุดการทำงาน
- **🔍 สแกนโฟลเดอร์**: นับโฟลเดอร์และไฟล์
- **🗑️ ล้างล็อก**: ล้างหน้าจอสถานะ

### 3. สถิติ
- **โฟลเดอร์**: จำนวนโฟลเดอร์ทั้งหมด
- **ไฟล์ PDF**: จำนวนไฟล์ PDF ทั้งหมด
- **สำเร็จ**: จำนวนไฟล์ที่ประมวลผลสำเร็จ
- **ข้อผิดพลาด**: จำนวนข้อผิดพลาด

### 4. สถานะการทำงาน (ล่าง)
แสดงล็อกการทำงานแบบเรียลไทม์:
- 🟢 **สีเขียว**: ความสำเร็จ
- 🔵 **สีน้ำเงิน**: ข้อมูล
- 🟡 **สีเหลือง**: คำเตือน
- 🔴 **สีแดง**: ข้อผิดพลาด

## 🔧 API Endpoints

### GET `/api/system/scan`
สแกนโฟลเดอร์ทั้งหมด

**Response:**
```json
{
  "success": true,
  "total_folders": 10,
  "total_files": 50,
  "folders": [
    {
      "name": "A.โฟร์เดอร์หลัก",
      "path": "V:/A.โฟร์เดอร์หลัก",
      "exists": true,
      "subfolders": 5,
      "files": 25
    }
  ]
}
```

### POST `/api/system/start`
เริ่มระบบ

**Request:**
```json
{
  "mode": "auto",
  "folders": ["all"]
}
```

**Response:**
```json
{
  "success": true,
  "message": "เริ่มระบบในโหมด: auto"
}
```

### POST `/api/system/stop`
หยุดระบบ

**Response:**
```json
{
  "success": true,
  "message": "ส่งคำสั่งหยุดระบบแล้ว"
}
```

### GET `/api/system/status`
ดูสถานะ

**Response:**
```json
{
  "running": true,
  "current_folder": "V:/A.โฟร์เดอร์หลัก/Build000",
  "processed": 5,
  "errors": 0,
  "total_folders": 10,
  "total_files": 50
}
```

### POST `/api/system/test`
ทดสอบระบบ

**Response:**
```json
{
  "success": true,
  "message": "ทดสอบระบบเสร็จสิ้น",
  "results": {
    "โฟลเดอร์": "A.โฟร์เดอร์หลัก: ✓, AA.โฟรเดอร์หลัก: ✓",
    "โมดูล": "✓ ทุกโมดูลพร้อมใช้งาน",
    "Playwright": "✓ พร้อมใช้งาน",
    "LINE OA": "✓ ตั้งค่าแล้ว"
  }
}
```

## 💡 เคล็ดลับการใช้งาน

1. **ทดสอบก่อนรัน**: ใช้ปุ่ม "🧪 ทดสอบระบบ" ก่อนทุกครั้ง
2. **สแกนโฟลเดอร์**: ใช้ปุ่ม "🔍 สแกนโฟลเดอร์" เพื่อดูว่ามีไฟล์ใหม่หรือไม่
3. **ใช้โหมดอัตโนมัติ**: สะดวกกว่าการเลือกทีละโฟลเดอร์
4. **ดูล็อก**: ติดตามสถานะการทำงานจากส่วน "สถานะการทำงาน"

## ⚠️ ข้อควรระวัง

- ❗ **อย่าปิด Terminal/CMD**: ระบบจะหยุดทำงานทันที
- ❗ **อย่าปิดเบราว์เซอร์**: จะไม่เห็นสถานะอัปเดต (แต่ระบบยังทำงานต่อ)
- ❗ **ตรวจสอบ LINE Token**: ให้ตั้งค่าใน `config.py` ก่อนรัน

## 🐛 แก้ไขปัญหา

### ปัญหา: ไม่สามารถเข้า http://localhost:5000
**แก้ไข:**
- ตรวจสอบว่า `control_api.py` รันอยู่หรือไม่
- ลองใช้ `http://127.0.0.1:5000` แทน
- ตรวจสอบว่า Port 5000 ไม่ถูกใช้งานโดยโปรแกรมอื่น

### ปัญหา: กดเริ่มทำงานแล้วไม่มีอะไรเกิดขึ้น
**แก้ไข:**
- เปิด Console ของเบราว์เซอร์ (F12) ดู error
- ตรวจสอบ Terminal/CMD ว่ามี error หรือไม่
- ลองกด "🧪 ทดสอบระบบ" ก่อน

### ปัญหา: Playwright ไม่พร้อม
**แก้ไข:**
```bash
python -m playwright install
```

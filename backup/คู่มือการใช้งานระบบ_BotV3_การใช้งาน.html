5 ขั้นตอนง่ายๆ สำหรับผู้ใช้ทั่วไป

🏠 หน้าหลัก 🚀 แนะนำระบบ 📝 สร้างฐานข้อมูล ✏️ แก้ไขไฟล์
🎯

ทำตาม 5 ขั้นตอนนี้!

ง่ายมาก ไม่ต้องกังวล

1เลือกโหมด

📁 กำหนดโฟลเดอร์เอง
👆

คลิกปุ่มนี้ในส่วนเลือกโฟลเดอร์หลัก

ปุ่มนี้จะแสดงอยู่เสมอสำหรับผู้ใช้ทั่วไป

2เลือกโฟลเดอร์

📂 เลือกโฟลเดอร์
📂

เลือกโฟลเดอร์ที่มีไฟล์ PDF

การเลือกโฟลเดอร์จะต้องเข้าไปที่โฟลเดอร์ที่เลือก >> ลูกค้า >> ระบบอัตโนมัติ

📷 หน้าต่างเลือกโฟลเดอร์

ตัวอย่างหน้าต่างเลือกโฟลเดอร์ - เลือกโฟลเดอร์ที่ต้องการประมวลผล PDF

💡 เคล็ดลับ

เลือกโฟลเดอร์ที่มี PDF โดยตรง (ไม่เข้าไปในโฟลเดอร์ย่อย)

ระบบจะสแกนไฟล์ PDF ทั้งหมดในโฟลเดอร์ที่เลือก

3ดูข้อมูล

📊

ระบบจะแสดงข้อมูลต่างๆ ดังนี้:

• รหัสโฟลเดอร์ (เช่น Build000, Build001)

• ประเภทภาษีมูลค่าเพิ่ม (VAT หรือ NoneVat)

• ข้อมูลจากไฟล์ JSON (ถ้ามี)

• ปุ่มสำหรับแก้ไขข้อมูล

📋 ข้อมูลที่ระบบจะแสดง
  • รหัสโฟลเดอร์: ระบุโฟลเดอร์ที่เลือก
  • ประเภทภาษี: VAT (จดภาษี) หรือ NoneVat (ยังไม่จด)
  • ข้อมูลบริษัท: จากไฟล์ JSON ถ้ามี
  • ปุ่มจัดการ: แก้ไขข้อมูล JSON และ TXT

4แก้ไขข้อมูล (ถ้าต้องการ)

✏️ แก้ไขผังบัญชี
📄 แก้ไขข้อมูล login
📊 จัดการข้อมูลภาษี
🔧

แก้ไขข้อมูลให้ถูกต้อง (ไม่บังคับ)

หากข้อมูลถูกต้องแล้ว สามารถข้ามขั้นตอนนี้ได้

ℹ️ หมายเหตุ

การแก้ไขข้อมูลจะช่วยให้ผลลัพธ์แม่นยำขึ้น

หากไม่แน่ใจ สามารถใช้ข้อมูลเดิมได้

5เริ่มทำงาน

▶️ เริ่มการทำงาน
🚀

คลิกแล้วรอผลลัพธ์!

ระบบจะแสดงความคืบหน้าในหน้าจอ

📊 ระบบจะแสดงผลลัพธ์
  • จำนวนไฟล์ PDF: ทั้งหมดที่พบในโฟลเดอร์
  • ไฟล์ที่อ่านสำเร็จ: สามารถดึงข้อมูลได้
  • ไฟล์ที่อ่านไม่ได้: มีปัญหาหรือเสียหาย
  • สถิติสรุป: รายงานผลการประมวลผล

🎉 เสร็จแล้ว!

ระบบจะแสดงผลลัพธ์ในหน้าจอ: จำนวนไฟล์, ไฟล์สำเร็จ, ไฟล์ไม่สำเร็จ

หากเปิดใช้งาน LINE Notify จะส่งแจ้งเตือนผลลัพธ์ทันที

💡 เคล็ดลับการใช้งาน

🎯 สำหรับผู้ใช้ใหม่
  • เริ่มต้นด้วยโหมด "กำหนดโฟลเดอร์เอง" เสมอ
  • เลือกโฟลเดอร์ที่มีไฟล์ PDF ไม่เยอะเกินไป (แนะนำไม่เกิน 60 ไฟล์)
  • เนื่องจากว่าบอทมีการทำงานที่ซับซ้อนมากขึ้นถ้าวางไฟล์เยอะๆ อาจทำให้บอททำงานช้าลง
⚡ เพิ่มประสิทธิภาพ
  • ตรวจสอบไฟล์ PDF ก่อนประมวลผล (ไม่มีรหัสผ่าน, ไม่เสียหาย)
  • แก้ไขข้อมูล ผังบัญชี ให้ถูกต้องเพื่อการทำงานที่ถูกต้อง
  • แก้ไขข้อมูล ข้อมูล login ให้ถูกต้องเพื่อการทำงานที่ถูกต้อง
  • ใช้ LINE Notify เพื่อรับผลลัพธ์ทันที
🔧 การแก้ไขปัญหา
  • หากไฟล์มีการย้ายไปยัง >> ผลการประมวลผล ให้ตรวจสอบตามนี้
  • - 1. เอกสารฐานข้อมูลไม่เรียบร้อย คือ เอกสารที่ไม่มีผังบัญชี
  • - 2. เอกสารรอดำเนินการ คือ เอกสารที่อ่านได้บางส่วน อาจจะเกิดจากมีการเปลี่ยนแบบฟอร์มของไฟล์ทำให้ระบบอ่านได้บางส่วน
  • - 3. เอกสารอ่านข้อมูลไม่ได้ คือ เอกสารที่เป็นประเภทรูปภาพ หรือ เป็นเอกสารที่ระบบไม่รู้จักและยังไม่ได้ทำเข้าระบบบอท

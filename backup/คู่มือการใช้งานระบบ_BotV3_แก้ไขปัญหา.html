มีปัญหา? ดูที่นี่!

วิธีแก้ปัญหาง่ายๆ

❌
ไม่พบไฟล์ PDF

ระบบไม่พบไฟล์ PDF ในโฟลเดอร์ที่เลือก

🔧 วิธีแก้ไข

• ตรวจสอบโฟลเดอร์ที่เลือก

• ตรวจสอบว่ามีไฟล์ .pdf หรือไม่

• ตรวจสอบสิทธิ์การเข้าถึงโฟลเดอร์

• เลือกโฟลเดอร์ที่ถูกต้องใหม่

❌
อ่าน PDF ไม่ได้

ระบบไม่สามารถอ่านข้อมูลจากไฟล์ PDF ได้

🔧 วิธีแก้ไข

• ตรวจสอบว่าไฟล์ PDF เสียหายหรือไม่

• ตรวจสอบว่าไฟล์มีรหัสผ่านหรือไม่

• ลองเปิดไฟล์ PDF ในโปรแกรมอื่น

• ใช้ไฟล์ PDF อื่นทดแทน

❌
ไม่พบข้อมูล JSON

ระบบแสดงข้อความ "ไม่พบไฟล์ JSON"

🔧 วิธีแก้ไข

• ใช้ปุ่ม "แก้ไขผังบัญชี"

• สร้างไฟล์ JSON ใหม่

• ตรวจสอบตำแหน่งไฟล์

• ติดต่อผู้ดูแลระบบ

❌
แก้ไขไฟล์ไม่ได้

ไม่สามารถแก้ไขข้อมูล JSON หรือ TXT ได้

🔧 วิธีแก้ไข

• ตรวจสอบสิทธิ์การเข้าถึงไฟล์

• ปิดโปรแกรมอื่นที่เปิดไฟล์อยู่

• ตรวจสอบว่าไฟล์ไม่ถูกล็อค

• ลองสร้างไฟล์ใหม่

❌
ระบบทำงานช้า

การประมวลผลใช้เวลานานมาก

🔧 วิธีแก้ไข

• ลดจำนวนไฟล์ PDF ต่อครั้ง

• ตรวจสอบพื้นที่ว่างในฮาร์ดดิสก์

• ปิดโปรแกรมอื่นที่ไม่จำเป็น

• รีสตาร์ทระบบ

❌
LINE Notify ไม่ทำงาน

ไม่ได้รับแจ้งเตือนผ่าน LINE

🔧 วิธีแก้ไข

• ตรวจสอบการเปิดใช้งาน LINE Notify

• ตรวจสอบ Token ของ LINE Notify

• ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต

• ลองส่งข้อความทดสอบ

💡 เคล็ดลับการใช้งาน

🎯
การเลือกโฟลเดอร์
  • เลือกโฟลเดอร์ที่มีไฟล์ PDF ไม่เยอะเกินไป
  • แนะนำไม่เกิน 50 ไฟล์ต่อครั้ง
  • ตรวจสอบไฟล์ PDF ก่อนประมวลผล
  • ใช้โหมด "กำหนดโฟลเดอร์เอง" สำหรับผู้ใช้ใหม่
⚡
เพิ่มประสิทธิภาพ
  • ปิดโปรแกรมอื่นที่ไม่จำเป็น
  • ตรวจสอบพื้นที่ว่างในฮาร์ดดิสก์
  • ใช้ SSD แทน HDD เพื่อความเร็ว
  • เพิ่ม RAM หากจำเป็น
🔧
การแก้ไขปัญหา
  • อ่านข้อความผิดพลาดให้ครบถ้วน
  • ตรวจสอบไฟล์ฐานข้อมูลให้ถูกต้อง
  • ทดสอบกับไฟล์เล็กๆ ก่อน
  • บันทึกข้อมูลทุกครั้งหลังแก้ไข
📱
LINE Notify
  • ตั้งค่า Token ให้ถูกต้อง
  • ทดสอบการส่งข้อความก่อนใช้งาน
  • ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต
  • เปิดใช้งานแจ้งเตือนใน LINE

🔍 การตรวจสอบปัญหา

📋
ตรวจสอบไฟล์
  • ไฟล์ PDF ไม่เสียหาย
  • ไฟล์ไม่มีรหัสผ่าน
  • ไฟล์มีนามสกุล .pdf
  • ไฟล์ไม่ถูกล็อค
📁
ตรวจสอบโฟลเดอร์
  • โฟลเดอร์มีไฟล์ PDF
  • มีสิทธิ์เข้าถึงโฟลเดอร์
  • โฟลเดอร์ไม่ถูกล็อค
  • เส้นทางโฟลเดอร์ถูกต้อง
⚙️
ตรวจสอบระบบ
  • พื้นที่ว่างในฮาร์ดดิสก์เพียงพอ
  • RAM เพียงพอสำหรับการทำงาน
  • โปรแกรมอื่นไม่แย่งทรัพยากร
  • ระบบไม่ถูกล็อค
🌐
ตรวจสอบเครือข่าย
  • การเชื่อมต่ออินเทอร์เน็ตเสถียร
  • ไม่มีการบล็อก Firewall
  • Token LINE Notify ถูกต้อง
  • เซิร์ฟเวอร์ LINE ไม่ล่ม

📞 การขอความช่วยเหลือ

📞 เมื่อไหร่ที่ควรขอความช่วยเหลือ

หากลองแก้ไขปัญหาตามคู่มือแล้วยังไม่ได้ผล

หรือพบปัญหาที่ไม่ปรากฏในคู่มือนี้

📋
ข้อมูลที่ต้องเตรียม
  • ข้อความผิดพลาดที่แสดง
  • ขั้นตอนที่ทำให้เกิดปัญหา
  • ข้อมูลระบบ (OS, RAM, HDD)
  • จำนวนไฟล์ PDF ที่ประมวลผล
🔍
การทดสอบเบื้องต้น
  • ทดสอบกับไฟล์ PDF 1-2 ไฟล์
  • ทดสอบในโฟลเดอร์อื่น
  • รีสตาร์ทโปรแกรม
  • ตรวจสอบไฟล์ฐานข้อมูล

🎉 เคล็ดลับสุดท้าย

เลือกโฟลเดอร์ที่ถูกต้อง + ตรวจสอบข้อมูล JSON + ทดสอบก่อนทำงาน = สำเร็จ!

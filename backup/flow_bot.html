🔧 Error Handling & Recovery

⚠️ Error Scenarios & Solutions

🔴 Connection Errors

  • EPIPE Error: ตรวจสอบ connection และรีเซ็ต browser
  • Page Timeout: ตรวจสอบ page health และรีเฟรชหน้า
  • Element Not Found: ใช้หลาย selector และรอให้ element โหลด

🟡 Form Validation Errors

  • Customer ID ไม่พบ: retry ≤ 3 ครั้ง
  • Modal ปรากฏ: ปิด modal และรีเซ็ตหน้า
  • ข้อมูลไม่ครบ: ตรวจสอบ PDF data และกรอกใหม่

🟠 Web Automation Errors

  • Save Timeout: รอผลบันทึกและตรวจสอบ status
  • VAT ไม่ตรง: แก้ไข VAT และตรวจสอบซ้ำ
  • Upload Failed: ตรวจสอบไฟล์และลองอัปโหลดใหม่

⚙️ Key Components

🤖 MainSystemOrchestrator

ตัวจัดการหลักที่ควบคุมการทำงานทั้งหมด รับผิดชอบการสแกนโฟลเดอร์ การประสานงานระหว่างโมดูลต่างๆ และการจัดการ lifecycle ของระบบ

📄 PDFReader

โมดูลอ่านและแยกข้อมูลจากไฟล์ PDF รองรับการประมวลผลแบบ batch และการจำแนกบริษัทอัตโนมัติ

🌐 WebAutomationPlaywright

ระบบควบคุมเว็บไซต์ PeakEngine ใช้ Playwright สำหรับการกรอกฟอร์ม การจัดการ error และการตรวจสอบการค้างของหน้าเว็บ

📁 FileManager

จัดการไฟล์และโฟลเดอร์ สร้างไฟล์ PDF ใหม่ การย้ายไฟล์ และการจัดการโครงสร้างโฟลเดอร์

📊 ReportManager

รวบรวมสถิติการทำงาน สร้างรายงาน และส่งการแจ้งเตือนผ่าน LINE Notify และ LINE OA

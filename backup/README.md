# ระบบบอทอัตโนมัติสำหรับประมวลผลเอกสาร PDF

ระบบบอทอัตโนมัติที่ออกแบบมาเพื่ออ่านข้อมูลจากไฟล์ PDF และทำงานกับเว็บไซต์ Peak Engine แบบอัตโนมัติ

## คุณสมบัติหลัก

- **PDF Processing**: อ่านและดึงข้อมูลจากไฟล์ PDF อัตโนมัติ
- **Web Automation**: ทำงานกับเว็บไซต์ Peak Engine แบบอัตโนมัติ
- **File Management**: จัดการไฟล์และโฟลเดอร์ตามโครงสร้างที่กำหนด
- **Data Processing**: ประมวลผลข้อมูลและจัดกลุ่มตามประเภทบริษัท
- **Logging & Reporting**: บันทึกการทำงานและสร้างรายงาน Excel/Text

## โครงสร้างระบบ

```
BotV3/
├── config.py              # การตั้งค่าระบบ
├── file_manager.py        # จัดการไฟล์และโฟลเดอร์
├── pdf_reader.py          # อ่านข้อมูลจาก PDF
├── web_automation.py      # ทำงานกับเว็บไซต์
├── data_processor.py      # ประมวลผลข้อมูล
├── logger.py              # บันทึกการทำงาน
├── main_bot.py            # ควบคุมการทำงานหลัก
├── requirements.txt       # Dependencies
└── README.md             # คู่มือการใช้งาน
```

## การติดตั้ง

1. ติดตั้ง Python 3.8 หรือสูงกว่า
2. ติดตั้ง dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. ติดตั้ง Chrome WebDriver (จะติดตั้งอัตโนมัติผ่าน webdriver-manager)

## ขั้นตอนการทำงาน

### ขั้นตอนที่ 1: อ่านโฟลเดอร์หลัก
- ระบบจะเข้าไปอ่านในโฟลเดอร์ V (หรือ Synology)
- หาโฟลเดอร์ที่ขึ้นต้นด้วย A, AA, AAA
- ข้ามโฟลเดอร์: #recycle, #snapshot, A.BMUT, A.Buildmeup, A.งานนอก

### ขั้นตอนที่ 2: อ่านโฟลเดอร์ลูกค้า
- เข้าไปในโฟลเดอร์ "ลูกค้า"
- หาโฟลเดอร์ "ระบบอัตโนมัติ"
- อ่านไฟล์ PDF ทั้งหมด

### ขั้นตอนที่ 3: อ่านข้อมูลการตั้งค่า
- อ่านไฟล์ JSON config (เช่น 001.json)
- อ่านไฟล์ folder_settings.json
- อ่านข้อมูล login จากไฟล์ txt

### ขั้นตอนที่ 4: ประมวลผล PDF
- ดึงข้อมูลจากไฟล์ PDF
- จับคู่กับข้อมูลบริษัท
- กำหนดกลุ่มตาม folder_settings

### ขั้นตอนที่ 5: ทำงานกับเว็บไซต์
- ล็อกอินเข้า Peak Engine
- ไปยัง Link Company และ Link Express
- กรอกข้อมูลในฟอร์ม
- อัปโหลดไฟล์

### ขั้นตอนที่ 6: จัดระเบียบไฟล์
- สร้างไฟล์ใหม่ตามชื่อที่กำหนด
- จัดกลุ่มไฟล์ตามประเภท (VAT/No VAT)
- สร้างโฟลเดอร์ผลลัพธ์

### ขั้นตอนที่ 7: สร้างรายงาน
- รายงาน Excel (bot_log.xlsx)
- รายงานข้อความ (bot_report.txt)

## การจัดการข้อผิดพลาด

ระบบมีการจัดการข้อผิดพลาดในหลายระดับ:
- **File Level**: ตรวจสอบการมีอยู่ของไฟล์และโฟลเดอร์
- **PDF Level**: จัดการข้อผิดพลาดในการอ่าน PDF
- **Web Level**: จัดการ timeout และการเชื่อมต่อเว็บ
- **Data Level**: ตรวจสอบความถูกต้องของข้อมูล

## การติดตามและรายงาน

### Log Files
- `bot_log.txt`: บันทึกการทำงานแบบละเอียด
- `bot_report.txt`: รายงานสรุปการทำงาน
- `bot_log.xlsx`: รายงาน Excel พร้อมสถิติ

### สถิติการทำงาน
- จำนวนไฟล์ที่ประมวลผล
- อัตราความสำเร็จ
- เวลาที่ใช้ในการทำงาน
- รายละเอียดข้อผิดพลาด

## การพัฒนาต่อ

### ส่วนที่ต้องพัฒนาต่อ
1. **Form Filling**: การกรอกข้อมูลในฟอร์มเว็บ
2. **File Upload**: การอัปโหลดไฟล์
3. **Processing Status**: การตรวจสอบสถานะการประมวลผล
4. **Error Recovery**: การกู้คืนจากข้อผิดพลาด

### การเพิ่มฟีเจอร์ใหม่
- เพิ่มการรองรับไฟล์ประเภทอื่น
- เพิ่มการทำงานกับเว็บไซต์อื่น
- เพิ่มการประมวลผลข้อมูลแบบ batch
- เพิ่มการแจ้งเตือนผ่าน email/SMS

## การแก้ไขปัญหา

### ปัญหาที่พบบ่อย
1. **Chrome WebDriver**: ตรวจสอบการติดตั้ง Chrome และ WebDriver
2. **File Permissions**: ตรวจสอบสิทธิ์การเข้าถึงไฟล์และโฟลเดอร์
3. **Network Issues**: ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต
4. **PDF Format**: ตรวจสอบรูปแบบไฟล์ PDF

### การ Debug
- เปิดใช้งาน logging แบบ verbose
- ใช้ screenshot เพื่อตรวจสอบหน้าจอ
- ตรวจสอบ log files เพื่อหาสาเหตุข้อผิดพลาด

## การสนับสนุน

หากพบปัญหาหรือต้องการความช่วยเหลือ:
1. ตรวจสอบ log files
2. ตรวจสอบการตั้งค่าใน config.py
3. ตรวจสอบโครงสร้างโฟลเดอร์
4. ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต

ระบบประมวลผล PDF อัตโนมัติ

🏠 หน้าหลัก 📁 การใช้งาน 📝 สร้างฐานข้อมูล
📄

อ่าน PDF → แยกข้อมูล → บันทึกผลลัพธ์

ระบบจะทำงานให้คุณอัตโนมัติ!

📄
อ่านไฟล์ PDF

สแกนข้อมูลอัตโนมัติจากไฟล์ PDF ทั้งหมดในโฟลเดอร์ที่เลือก

🔍
แยกข้อมูลสำคัญ

ดึงข้อมูลสำคัญ: ชื่อบริษัท, รหัสผู้ติดต่อ, โค้ดบัญชี

💾
บันทึกผลลัพธ์

บันทึกข้อมูลในรูปแบบ JSON หรือ TXT พร้อมรายงานสถิติ

📱
แจ้งเตือน LINE

ส่งผลลัพธ์ผ่าน LINE Notify ทันทีเมื่อประมวลผลเสร็จ

🎯 เลือกโหมดการทำงาน

💡 แนะนำ: ใช้โหมด "กำหนดโฟลเดอร์เอง"

ง่ายที่สุด เหมาะสำหรับผู้ใช้ทั่วไป! สามารถเลือกโฟลเดอร์ที่ต้องการประมวลผลได้โดยตรง

🔄
โหมดอัตโนมัติ

สแกนโฟลเดอร์ทั้งหมดตามที่กำหนดไว้ในระบบ

เหมาะสำหรับ: การประมวลผลแบบรวม

✋
เลือกโฟลเดอร์หลักเอง

เลือกโฟลเดอร์หลักจากรายการที่ระบบสแกนพบ

เหมาะสำหรับ: การเลือกโฟลเดอร์หลักเฉพาะ

📁
กำหนดโฟลเดอร์เอง

เลือกโฟลเดอร์เฉพาะที่ต้องการประมวลผลได้โดยตรง

เหมาะสำหรับ: ผู้ใช้ทั่วไป - ง่ายและรวดเร็ว

🌟 ฟีเจอร์เด่นของ BotV3

🎨
Interface ใช้งานง่าย

หน้าจอสวยงาม เข้าใจง่าย เหมาะสำหรับผู้ใช้ทุกระดับ

⚡
ประมวลผลเร็ว

ใช้เทคโนโลยีล่าสุดในการอ่านและประมวลผลไฟล์ PDF

🔒
ระบบรักษาความปลอดภัย

มีระบบแอดมินแยกจากผู้ใช้ทั่วไป ป้องกันการใช้งานผิดวัตถุประสงค์

📊
รายงานสถิติ

แสดงสถิติการประมวลผล: จำนวนไฟล์, สำเร็จ, ไม่สำเร็จ

🔧
แก้ไขข้อมูลได้

สามารถแก้ไขข้อมูล JSON และ TXT ผ่านหน้าจอระบบ

📱
แจ้งเตือน LINE

ส่งผลลัพธ์ผ่าน LINE Notify พร้อมรายละเอียดครบถ้วน

🚀 เริ่มต้นใช้งาน

🎯

เพียง 5 ขั้นตอนง่ายๆ

คุณจะสามารถใช้งาน BotV3 ได้ทันที!

1️⃣
เลือกโหมด

เลือก "กำหนดโฟลเดอร์เอง" สำหรับการใช้งานทั่วไป

2️⃣
เลือกโฟลเดอร์

คลิก "เลือกโฟลเดอร์" และเลือกโฟลเดอร์ที่มีไฟล์ PDF

3️⃣
ดูข้อมูล

ระบบจะแสดงข้อมูลโฟลเดอร์และประเภทภาษี

4️⃣
แก้ไขข้อมูล (ไม่บังคับ)

แก้ไขข้อมูล JSON/TXT หากต้องการ

5️⃣
เริ่มทำงาน

คลิก "เริ่มการทำงาน" และรอผลลัพธ์!

🎉 เสร็จแล้ว!

ระบบจะแสดงผลลัพธ์ในหน้าจอ: จำนวนไฟล์, ไฟล์สำเร็จ, ไฟล์ไม่สำเร็จ และส่งแจ้งเตือนผ่าน LINE (หากเปิดใช้งาน)

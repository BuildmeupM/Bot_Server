สร้างฐานข้อมูลใหม่

สำหรับรหัสโฟลเดอร์ที่ยังไม่มีข้อมูล!

💡 เมื่อไหร่ที่ต้องสร้างฐานข้อมูล?

เมื่อระบบแสดงข้อความ "ไม่พบไฟล์ JSON" หรือ "ไม่พบไฟล์ TXT" สำหรับรหัสโฟลเดอร์ใหม่

หรือเมื่อต้องการสร้างข้อมูลสำหรับรหัสโฟลเดอร์ที่เพิ่งสร้างขึ้นใหม่

1ตรวจสอบสถานะ

🔍
ระบบจะแสดงข้อความเตือน

เมื่อไม่พบไฟล์ฐานข้อมูลสำหรับรหัสโฟลเดอร์ที่เลือก

เช่น: "ไม่พบไฟล์ JSON: Buildxxx.json"

⚠️ ข้อควรระวัง

หากไม่พบไฟล์ฐานข้อมูล ระบบจะไม่สามารถประมวลผลข้อมูลได้อย่างถูกต้อง

จำเป็นต้องสร้างไฟล์ฐานข้อมูลก่อนเริ่มการประมวลผล

2เลือกประเภทการสร้าง

📄
📝 สร้างไฟล์ JSON

สร้างไฟล์ผังบัญชี

มีโครงสร้างบริษัทและข้อมูลบัญชี

ใช้สำหรับ: ข้อมูลบริษัทและรหัสบัญชี

📄
📝 สร้างไฟล์ TXT

สร้างไฟล์ข้อมูล login

มี Username, Password, Link

ใช้สำหรับ: ข้อมูลการเข้าสู่ระบบ

📄
📝 สร้างทั้งคู่

สร้างไฟล์ JSON และ TXT พร้อมกัน

แนะนำสำหรับผู้ใช้ใหม่!

ใช้สำหรับ: การตั้งค่าเริ่มต้น

📝 สร้างไฟล์ JSON
📝 สร้างไฟล์ TXT
📝 สร้างทั้งคู่

3จัดการข้อมูลภาษี

📊 จัดการข้อมูลภาษี
🟢
VAT - จดภาษีมูลค่าเพิ่ม

สำหรับบริษัทที่จดทะเบียนภาษีมูลค่าเพิ่มแล้ว

จะใช้ระบบประมวลผลแบบปกติ

🟡
NoneVat - ยังไม่ได้จดภาษีมูลค่าเพิ่ม

สำหรับบริษัทที่ยังไม่ได้จดทะเบียนภาษีมูลค่าเพิ่ม

จะใช้ระบบประมวลผลแบบพิเศษ

💡 การเลือกประเภทภาษี

เลือกให้ตรงกับสถานะจริงของบริษัท เพื่อให้ระบบประมวลผลได้อย่างถูกต้อง

สามารถเปลี่ยนได้ในภายหลังผ่านปุ่ม "จัดการข้อมูลภาษี"

4รีเฟรชข้อมูล

🔄 รีเฟรชข้อมูล
🔄
อัพเดตข้อมูลล่าสุด

คลิกเพื่อดูข้อมูลที่สร้างใหม่

ระบบจะแสดงข้อมูลโฟลเดอร์และไฟล์ฐานข้อมูลที่เพิ่งสร้าง

✅ ฐานข้อมูลพร้อมใช้งาน!

ตอนนี้คุณสามารถแก้ไขข้อมูลและเริ่มการประมวลผลได้แล้ว

ระบบจะใช้ข้อมูลที่สร้างขึ้นในการประมวลผลไฟล์ PDF

📋 รายละเอียดไฟล์ฐานข้อมูล

📄
ไฟล์ JSON

ชื่อไฟล์: Buildxxx.json

ตำแหน่ง: V:/A.โฟร์เดอร์หลัก/Build000 ทดสอบระบบ/รหัส/

เนื้อหา: ข้อมูลบริษัท, รหัสผู้ติดต่อ, โค้ดบัญชี

📄
ไฟล์ TXT

ชื่อไฟล์: Buildxxx.txt

ตำแหน่ง: V:/A.โฟร์เดอร์หลัก/Build000 ทดสอบระบบ/รหัส/

เนื้อหา: Username, Password, Link company, Link Express

📊
ไฟล์ Tax Settings

ชื่อไฟล์: folder_settings.json

ตำแหน่ง: V:/A.โฟร์เดอร์หลัก/Build000 ทดสอบระบบ/folder_settings/

เนื้อหา: ประเภทภาษีของแต่ละรหัสโฟลเดอร์

⚠️ ข้อควรระวัง

⚠️ การสร้างไฟล์ JSON

  • ไฟล์ JSON จะคัดลอกโครงสร้างจาก Build000 ทดสอบระบบเป็นฐานข้อมูลหลัก
  • ข้อมูลส่วนตัว (รหัสผู้ติดต่อ, โค้ดบัญชี) จะเป็นค่าว่าง
  • จำเป็นต้องแก้ไขข้อมูลให้ถูกต้องหลังสร้างไฟล์

⚠️ การสร้างไฟล์ TXT

  • ไฟล์ TXT จะมีโครงสร้างพื้นฐานพร้อมให้กรอกข้อมูล
  • Username และ Password จะเป็นค่าว่าง
  • Link company และ Link Express จะเป็นค่าว่าง

💡 เคล็ดลับ

สร้างไฟล์ฐานข้อมูลให้ครบถ้วนก่อนเริ่มการประมวลผล

แก้ไขข้อมูลให้ถูกต้องเพื่อผลลัพธ์ที่แม่นยำ

ใช้ปุ่ม "สร้างทั้งคู่" สำหรับการตั้งค่าเริ่มต้นที่สมบูรณ์

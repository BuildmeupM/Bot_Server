# 🖥️ BotV3 Desktop Application - UI แบบใหม่

Desktop Application ที่มี UI สวยงามเหมือนหน้าเว็บ ไม่ต้องใช้ Web Browser

---

## 🎨 **UI ใหม่ที่ปรับปรุงแล้ว**

### **1. โหมดการเลือกโฟลเดอร์**
```
┌─────────────────────────────────────────┐
│ 📁 เลือกโฟลเดอร์หลัก                    │
├─────────────────────────────────────────┤
│ [โหมดอัตโนมัติ] [เลือกเอง] ← ปุ่มสวยงาม  │
└─────────────────────────────────────────┘
```

### **2. การแสดงโฟลเดอร์แบบ Card**
```
┌─────────────────────────────────────────┐
│ ☑ 📁 A.โฟร์เดอร์หลัก                   │
│   V:/A.โฟร์เดอร์หลัก                   │
│   กำลังตรวจสอบ...                       │
├─────────────────────────────────────────┤
│ ☑ 📁 AA.โฟรเดอร์หลัก                   │
│   V:/AA.โฟรเดอร์หลัก                   │
│   พร้อมใช้งาน                           │
└─────────────────────────────────────────┘
```

### **3. ปุ่มควบคุม**
```
┌─────────────────────────────────────────┐
│ [✓ เลือกทั้งหมด] [✗ ยกเลิกทั้งหมด]     │
├─────────────────────────────────────────┤
│ [▶️ เริ่มการทำงาน]                      │
│ [🔄 เริ่มระบบลูป]                       │
│ [⏹️ หยุดการทำงาน]                      │
│ [🧪 ทดสอบระบบ]                         │
└─────────────────────────────────────────┘
```

---

## ✨ **คุณสมบัติใหม่**

### **1. โหมดการทำงาน**
- **โหมดอัตโนมัติ** - เลือกโฟลเดอร์ทั้งหมดอัตโนมัติ
- **เลือกเอง** - เลือกโฟลเดอร์ที่ต้องการเอง

### **2. Folder Cards**
- ✅ **Checkbox** - เลือกได้หลายโฟลเดอร์
- 📁 **ไอคอนโฟลเดอร์** - สีทองสวยงาม
- 📝 **ชื่อโฟลเดอร์** - ตัวหนา ชัดเจน
- 📂 **Path เต็ม** - แสดงตำแหน่งไฟล์
- ⚡ **สถานะ** - กำลังตรวจสอบ/พร้อมใช้งาน

### **3. Hover Effects**
- 🎯 **เมาส์ชี้** - เปลี่ยนสีพื้นหลัง
- 🔵 **Border** - เปลี่ยนสีขอบ
- ✨ **Smooth** - เปลี่ยนสีเรียบ

### **4. การจัดการ**
- 📜 **Scroll** - เลื่อนดูโฟลเดอร์ได้
- 🖱️ **Mouse Wheel** - ใช้ล้อเมาส์เลื่อน
- 📏 **Auto Resize** - ปรับขนาดอัตโนมัติ

---

## 🚀 **วิธีใช้งาน**

### **วิธีที่ 1: รันจาก Python**
```bash
# 1. ติดตั้ง dependencies
pip install -r requirements_desktop.txt
playwright install chromium

# 2. รันโปรแกรม
python bot_gui_tkinter.py
```

### **วิธีที่ 2: รันจาก Batch (Windows)**
```bash
# Double-click ไฟล์
start_desktop_app.bat
```

### **วิธีที่ 3: รันจาก Python Script**
```bash
python run_desktop_app.py
```

## 🎯 **ขั้นตอนการใช้งาน**

### **1. เปิดโปรแกรม**
- Double-click `start_desktop_app.bat` หรือ
- รัน `python bot_gui_tkinter.py`

### **2. เลือกโหมด**
- **โหมดอัตโนมัติ** - เลือกโฟลเดอร์ทั้งหมด
- **เลือกเอง** - เลือกโฟลเดอร์ที่ต้องการ

### **3. เลือกโฟลเดอร์**
- ติ๊ก checkbox หน้าชื่อโฟลเดอร์หลัก (A.โฟร์เดอร์หลัก, AA.โฟรเดอร์หลัก, AAA.โฟรเดอร์หลัก)
- หรือกด "✓ เลือกทั้งหมด"
- หรือกด "✗ ยกเลิกทั้งหมด"
- ระบบจะสแกน Build* ด้านในอัตโนมัติ

### **4. เริ่มการทำงาน**
- **▶️ เริ่มการทำงาน** - รันครั้งเดียว
- **🔄 เริ่มระบบลูป** - รันต่อเนื่อง
- **🧪 ทดสอบระบบ** - ทดสอบกับ A.โฟร์เดอร์หลัก

### **5. ดูผลลัพธ์**
- ดู log ในหน้าจอขวา
- ดูสถานะในหน้าจอล่าง
- ดู progress bar

## 🔧 **การปรับแต่ง**

### **เปลี่ยนสี**
```python
# ใน bot_gui_tkinter.py
PRIMARY_COLOR = "#3498db"      # สีหลัก
LIGHT_COLOR = "#ecf0f1"        # สีอ่อน
DARK_COLOR = "#2c3e50"         # สีเข้ม
GOLD_COLOR = "#ffd700"         # สีทอง
```

### **เปลี่ยนขนาด**
```python
# ขนาดหน้าต่าง
self.root.geometry("1200x800")  # กว้าง x สูง

# ขนาด panel
left_panel = tk.Frame(main_container, width=400)
```

### **เปลี่ยนฟอนต์**
```python
# ฟอนต์หลัก
font=("Arial", 12, "bold")

# ฟอนต์รอง
font=("Arial", 9)
```

## 📱 **Responsive Design**

### **ขนาดหน้าจอ**
- **1200x800** - ขนาดแนะนำ
- **1000x600** - ขนาดขั้นต่ำ
- **Auto Resize** - ปรับขนาดอัตโนมัติ

### **การจัดวาง**
- **Left Panel** - 400px (โฟลเดอร์ + ควบคุม)
- **Right Panel** - ยืดหยุ่น (log)
- **Header** - 80px (ชื่อโปรแกรม)
- **Footer** - 30px (ลิขสิทธิ์)

## 🐛 **การแก้ปัญหา**

### **ปัญหา: UI ไม่แสดง**
```bash
# ตรวจสอบ tkinter
python -c "import tkinter; print('OK')"

# ถ้า error ให้ติดตั้ง
# Windows: tkinter มากับ Python แล้ว
# Linux: sudo apt-get install python3-tk
```

### **ปัญหา: โฟลเดอร์ไม่แสดง**
```bash
# ตรวจสอบ V: drive
dir V:\

# แก้ไข config.py
BASE_FOLDER = "C:/YourPath"
```

### **ปัญหา: Checkbox ไม่ทำงาน**
```bash
# ตรวจสอบ dependencies
pip install -r requirements_desktop.txt
```
